# SillyAgent

This repository's canonical SillyAgent development branch is **[main](https://github.com/Bulldogshot10/SillyAgent/tree/main)**.

The `release` branch is retained as a legacy upstream-derived SillyTavern branch and does **not** contain the complete SillyAgent core integration. For the SillyAgent native harness, automatic memory capture, background reflection, procedural skills, installation guide, and architecture documentation, use the `main` branch.
