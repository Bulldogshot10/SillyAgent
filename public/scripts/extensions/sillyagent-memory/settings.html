SillyAgent Memory

Autonomous memory is always on. SillyAgent captures chat turns, retrieves relevant memories, runs dreaming automatically, and enables native tool calling for supported Chat Completion providers.

Every character has an isolated memory. Durable user facts, preferences, goals, character identity, and relationship continuity are stored inside the active character’s own persistent memory. Temporary task context stays in the current chat. Dreaming can combine evidence across chats only when those chats belong to the same character. Nothing is manually selected or triggered.
